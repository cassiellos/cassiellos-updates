## 2. Segmentação geográfica

Base conhecida: **Belo Horizonte / região metropolitana (MG)**.

Não usar bairro, endereço ou "Pampulha" em segmentação ou em texto de anúncio
enquanto a localização e a área de atendimento não forem oficialmente
confirmadas. Depois da confirmação, ajustar o raio à área real de atendimento.

Recomendação de configuração de local: "Presença — pessoas que estão ou visitam
regularmente" (e não "presença ou interesse"), para evitar tráfego de fora da
área atendida.

## 3. Orçamento

Sugestão inicial de **validação**: **R$ 25,00/dia** de orçamento médio diário.
Faixa razoável para discussão: **R$ 20–30/dia**.

| Orçamento médio diário | Limite mensal aproximado (30,4 dias) |
| --- | --- |
| R$ 20,00 | ≈ R$ 608,00 |
| R$ 25,00 | ≈ R$ 760,00 |
| R$ 30,00 | ≈ R$ 912,00 |

O Google trabalha com **orçamento médio diário**: o gasto de um dia específico
pode ficar acima da média, respeitando o limite mensal calculado sobre 30,4 dias.

**Isto não é garantia de resultado.** Antes de ativar:

1. rodar o Planejador de Palavras-chave com dados atuais da região;
2. confirmar com a cliente orçamento mensal, CPC estimado, volume, região,
   serviço ofertado e **capacidade real de agenda**;
3. não aumentar orçamento sem autorização.

Estratégia de lances inicial sugerida: **Maximizar cliques com CPC máximo
limitado** enquanto não houver volume de conversões, migrando para **Maximizar
conversões / CPA desejado** somente depois que a conversão de WhatsApp estiver
registrando dados confiáveis.

## 4. Palavras-chave

Começar com **correspondência exata** e **de frase**. Não usar ampla neste
orçamento de validação.

### 4.1 Genéricas — ativar no lançamento

```
[studio de unhas bh]
"studio de unhas belo horizonte"
[nail designer bh]
"nail designer belo horizonte"
[manutenção de unhas bh]
"manutenção de unhas belo horizonte"
[unhas de alto padrão bh]
"unhas de alto padrão belo horizonte"
[studio nails bh]
"studio nails belo horizonte"
```

### 4.2 Marca — grupo separado

```
[studio macleny nails]
[macleny nails]
[jheniffer macleny]
```

Manter marca e genéricas em **grupos de anúncios separados**, para que o
relatório não misture demanda de marca com aquisição.

### 4.3 Condicionais — **não ativar ainda**

Só depois do **endereço confirmado**:

```
[nail designer pampulha]
"studio de unhas pampulha"
"manutenção de unhas pampulha"
```

Só depois dos **serviços confirmados** pela cliente:

```
"alongamento de unhas bh"
"alongamento em gel bh"
"unhas de gel bh"
"banho de gel bh"
```

> Esses termos aparecem na pesquisa de concorrência. Isso **não** significa que
> são serviços da Macleny. Anunciar um serviço não ofertado gera lead ruim,
> desgaste e risco de política.

### 4.4 Negativas iniciais

```
curso · cursos · curso online · aula · aulas · apostila · pdf
certificado · certificação · emprego · empregos · vaga · vagas
salário · salario · currículo · curriculo · trabalhar
trabalho nail designer · contratação
kit · kits · material · materiais · fornecedor · fornecedores
atacado · distribuidor · fabricante · esmalte atacado · comprar esmalte
tutorial · passo a passo · como fazer · faça você mesma
gratis · grátis · gratuito
```

Revisar o relatório de termos de pesquisa semanalmente nas primeiras 4 semanas.

### 4.5 Negativas que **não** devem ser aplicadas às cegas

`preço` · `valor` · `perto de mim` · `manicure` · `gel` · `Pampulha` · `BH`
— carregam intenção comercial real. Não bloquear sem dados.

`barato` · `baratinho` · `promoção` · `cupom` — podem ser avaliadas como filtro
de posicionamento premium, mas só depois de analisar volume, intenção e custo
reais. Não negativar automaticamente.

## 8. Conversão

**Ação de conversão primária:** `Contato WhatsApp | Studio Macleny Nails`
Categoria: **Lead / Contato** · Contagem: **uma por clique** (não "todas").

### Rota A — GTM (recomendada)

1. criar a ação de conversão no Google Ads e anotar **Conversion ID** e **Label**;
2. instalar o container do GTM (`NEXT_PUBLIC_GTM_ID`);
3. criar um acionador de **evento personalizado** `whatsapp_click`;
4. criar a tag **Google Ads Conversion Tracking** com o ID e o Label;
5. adicionar **Conversion Linker** quando aplicável;
6. publicar o container;
7. testar em Preview / Tag Assistant;
8. confirmar **um único disparo por clique**;
9. validar depois no diagnóstico de conversões do Google Ads.

Com o GTM configurado, o código do site **não** dispara a conversão — ele só
empurra o evento para o `dataLayer`. Isso evita contagem dupla.

### Rota B — Google Tag direto (sem GTM)

Preencher `NEXT_PUBLIC_GOOGLE_ADS_ID` e
`NEXT_PUBLIC_GOOGLE_ADS_WHATSAPP_LABEL`. Só então o site dispara
`gtag('event','conversion')`. Sem esses valores reais, nada é disparado — e
nenhum ID falso foi deixado no código.

### Teste obrigatório antes de otimizar por conversão

Testar clique a clique, em desktop e mobile: hero · serviço · CTA final · botão
flutuante · header · menu mobile. Cada clique deve gerar **exatamente um**
evento. "O código existe" não é teste.

### Dados pessoais

O evento carrega apenas `cta_location`, `service` e `destination_type`. Nenhum
nome, telefone, e-mail ou mensagem pessoal é enviado.

## 9. Checklist de destino (pré-lançamento)

Rodar **antes** de apontar qualquer anúncio para a página.
Automatizável em parte com `npm run check:config:strict`.

```
[ ] domínio oficial confirmado pela cliente
[ ] HTTPS válido, certificado sem erro
[ ] página retorna HTTP 200
[ ] abre em desktop e em mobile
[ ] acessível sem login
[ ] robots.txt acessível e sem Disallow: / em produção
[ ] Googlebot não bloqueado
[ ] Google AdsBot não bloqueado
[ ] sitemap.xml acessível com URLs canônicas reais
[ ] CSS/JS/imagens sem 403
[ ] nenhum asset crítico em 404
[ ] sem cadeia estranha de redirects
[ ] URL final não leva a outro domínio inesperado
[ ] canonical correto e consistente
[ ] sem auto-redirecionamento para WhatsApp (só após clique)
[ ] sem download automático e sem pop-up abusivo
[ ] sem scripts desconhecidos e sem mixed content
[ ] mesmo conteúdo para crawler e usuário (sem cloaking, sem texto escondido)
[ ] conteúdo original suficiente (não é página só de botão)
[ ] identidade empresarial visível e contato verdadeiro
[ ] Política de Privacidade disponível
[ ] nenhum placeholder de desenvolvimento visível
[ ] nenhum link quebrado
[ ] console sem erros críticos e Network sem falhas
```

### Diagnóstico técnico (não confie no "abre no meu navegador")

```bash
curl -I  https://SEU-DOMINIO
curl -L -I https://SEU-DOMINIO
curl -I  https://SEU-DOMINIO/robots.txt
curl -I  https://SEU-DOMINIO/sitemap.xml
```

Qualquer `403`, `404`, `5xx`, erro de DNS, erro de TLS ou loop de redirect
significa **destino não pronto**. Antes de simular o user-agent do AdsBot,
consultar a documentação oficial atual do Google para não usar uma string
desatualizada.

### Search Console (depois do domínio ativo)

Verificar propriedade · inspecionar URL · testar URL publicada · conferir robots
e canonical · enviar sitemap · checar segurança e ações manuais.
Isso **não** garante aprovação no Google Ads — reduz causas técnicas de reprovação.

### O que nunca fazer

Mascarar domínio, usar redirect suspeito, servir conteúdo diferente ao crawler,
esconder a página real, trocar o destino para driblar reprovação, usar encurtador
ou domínio intermediário, cloaking. Se o destino for reprovado, investigar a
causa real.
